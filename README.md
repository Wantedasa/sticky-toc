# Sticky Table of Contents 📑

Auto-build a TOC from headings and highlight the active section on scroll.

## What it is
A sticky table-of-contents builder. It scans the page for <h2> headings, builds a clickable list, and highlights the current section as you scroll using IntersectionObserver. No dependencies.

## Usage
```js
buildTOC(root, listEl)
```
